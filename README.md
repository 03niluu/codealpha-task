# 🚗 Vehicle's Canvas

**Vehicle's Canvas** is a responsive vehicle image gallery website designed to showcase different types of vehicles in a clean and visually appealing layout.

The gallery includes **Cars, Bikes, and Cycles**, with category-based filtering and an interactive image viewer for browsing images.

## ✨ Features

* 🚘 **Vehicle Gallery** with Cars, Bikes, and Cycles
* 🔍 **Category Filtering** using All, Cars, Bikes, and Cycles
* 🖼️ **Interactive Image Viewer** for viewing images in a larger format
* ◀️ **Previous / Next Navigation** inside the image viewer
* 📱 **Responsive Design** for desktop, tablet, and mobile screens
* 🎨 **Modern Dark UI** with blue/teal gradients and gold accents
* ✨ **Smooth Animations** for the header and interface elements
* 📐 **Responsive Gallery Layout** that adapts to different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Website structure and gallery content
* **CSS3** – Styling, responsive layout, animations, gradients, and UI design
* **JavaScript** – Gallery filtering and image viewer functionality

## 🚀 How to Run

1. Download or clone this repository.
2. Make sure the `html`, `css`, `javascript`, and `images` folders maintain the same structure.
3. Open `html/index.html` in a web browser.
4. Use the category buttons to filter vehicles.
5. Click an image to open the image viewer.
6. Use the previous and next buttons to navigate through images.

## 🎯 Key Features

### Vehicle Categories

The gallery provides four filtering options:

* **All**
* **Cars**
* **Bikes**
* **Cycles**

Each image is assigned a vehicle type, allowing the gallery to display only the selected category.

### Interactive Image Viewer

Clicking a vehicle image opens an image viewer with:

* Large image preview
* Previous image button
* Next image button
* Close button
* Dark overlay for focused viewing

### Responsive Design

The gallery adapts to different screen sizes. The layout changes from multiple columns on larger screens to fewer columns on tablets and a single-column layout on smaller mobile devices.
